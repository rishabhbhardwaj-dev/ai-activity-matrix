## 🚀 Usage

Embed the SVG directly into your GitHub Profile README.

```html

  <img
    src="https://raw.githubusercontent.com/rishabhbhardwaj-dev/ai-activity-matrix/main/contribution_grid_ai_matrix.svg"
    width="100%"
    alt="AI Activity Matrix"
  />
</p>
```
